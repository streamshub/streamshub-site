Flink SQL Runner simplifies running SQL queries using [Apache Flink](https://flink.apache.org/) on
Kubernetes. It provides a wrapper application and container image for the
[Flink Kubernetes Operator's](https://nightlies.apache.org/flink/flink-kubernetes-operator-docs-main/)
`FlinkDeployment` custom resource, letting you specify your SQL queries directly as arguments.
